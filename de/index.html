So sieht ein Screenshot professionell aus

Ein roher Screenshot ist eng beschnitten, hat harte Kanten und liegt meist auf der Farbe, die deine App gerade nutzt. In einem Tweet, auf einer Landingpage oder in einer Product-Hunt-Galerie wirkt das „unfertig“. Ein gutes Mockup behebt vier Dinge, und Screenshot Studio stellt jedes davon als Regler oder Kachel bereit.

  1. Gib dem Screenshot Luft. Innenabstand ist das größte einzelne Upgrade. Mit 48–96 px Platz rundherum können Schatten und Hintergrund ihre Wirkung entfalten; bei Social-Posts, in denen das Bild klein angezeigt wird, gehst du niedriger (24–40 px), damit die UI lesbar bleibt.
  2. Wähle einen kontrastierenden Hintergrund. Eine helle UI wirkt auf einem dunklen oder satten Verlauf am schärfsten (Mitternacht, Sonnenuntergang, Ozean); eine dunkle UI sticht auf Pfirsich, Mono oder einem blassen Mesh hervor. Der Verlauf sollte nicht mit deinen Markenfarben konkurrieren – im Zweifel nutzt du die eigenen Farbwähler und nimmst deine Logofarbe für einen der beiden Farbpunkte.
  3. Lieber weicher als harter Schatten. Eine Schattenstärke von 40–60 mit einem Versatz von 20–30 px ergibt einen natürlichen Look wie eine „schwebende Karte“. Dreh den Schatten nur auf, wenn der Hintergrund sehr hell ist.
  4. Wähle einen Rahmen, der zum Kontext passt. Ein Browser-Rahmen zeigt, dass es eine Web-App ist, und lässt dich die Domain in der Adressleiste anzeigen. Das Mac- oder Windows-Fenster wirkt wie eine Desktop-App. Der Smartphone-Rahmen ist für mobile Screenshots gedacht, idealerweise im Verhältnis 9:16 oder 4:5. „Keiner“ mit 12–16 px abgerundeten Ecken ist die sauberste Option für Dokumentationen und Blogartikel.

Schließe mit einer Bildunterschrift ab, wenn das Bild für sich allein stehen soll: ein kurzer Titel („Neu: Inbox Zero“) und ein einzeiliger Untertitel. Halte die Neigung unter 6°, außer du willst ein Hero-Banner; es wirkt dramatisch, aber Text im Screenshot wird schwerer lesbar.

Wer nutzt einen Screenshot-Verschönerer?

Indie-Maker und Startups nutzen es für Launch-Tweets, Changelog-Posts und den Bereich „Was ist neu“ einer Landingpage. Designer packen UI-Entwürfe in einen Rahmen, bevor sie sie auf Dribbble posten oder mit Kunden teilen. Technische Redakteure und Support-Teams fügen Innenabstand und einen dezenten Rahmen hinzu, damit Screenshots in der Dokumentation nicht mit dem Seitenhintergrund verschwimmen. Marketer gestalten ein ganzes Feature-Set im Stapel mit einem Preset, damit jedes Bild einer Kampagne einheitlich aussieht.

Alles bleibt auf deinem Gerät

Screenshot Studio ist eine statische Seite. Wenn du ein Bild hineinziehst, wird es im Arbeitsspeicher dekodiert, zusammen mit Hintergrund, Schatten und Rahmen auf einen Canvas gezeichnet und von deinem Browser wieder als PNG oder JPG kodiert. Es gibt keinen Upload-Endpunkt und kein serverseitiges Rendering, daher verlassen vertrauliche Dashboards, unveröffentlichte Funktionen und Kundendaten nie deinen Computer. Deine Stileinstellungen werden in localStorage gespeichert, damit sich das Tool genau so öffnet, wie du es verlassen hast.

Häufig gestellte Fragen

Ist Screenshot Studio kostenlos?

Ja. Alle Hintergründe, Rahmen, Layout-Steuerungen, Bildunterschriften und der Export als PNG/JPG in 1x sind kostenlos und ohne Anmeldung. Kostenlose Exporte tragen ein kleines Badge „Screenshot Studio · free“ in der Ecke. Das optionale einmalige Pro-Upgrade entfernt es und bietet Exporte in 2x/4x, Premium-Hintergründe, Stapel-Export als ZIP und unbegrenzt gespeicherte Stil-Presets.

Muss ich meinen Screenshot hochladen?

Nein. Das Mockup wird mit der HTML5-Canvas-API in deinem Browser gerendert. Dein Screenshot verlässt nie dein Gerät, nichts wird auf einem Server gespeichert, und das Tool funktioniert auch offline, sobald die Seite geladen ist.

Welche Bildformate kann ich nutzen?

Du kannst PNG-, JPG/JPEG-, WebP-, GIF- (erstes Bild) und BMP-Bilder hineinziehen, auswählen oder einfügen. Die Ausgabe ist PNG (mit Transparenz) oder JPG mit Qualität 92. HEIC-Fotos von iPhones werden von Browsern nicht dekodiert, exportiere sie also zuerst als JPEG.

Kann ich das Wasserzeichen entfernen?

Ja. Die kostenlose Version fügt Exporten unten rechts ein kleines Badge „Screenshot Studio · free“ hinzu. Screenshot Studio Pro, ein Einmalkauf, entfernt das Badge aus jedem Export, auch aus Downloads in 2x und 4x sowie Stapel-ZIPs.

Kann ich viele Screenshots auf einmal gestalten?

Mit Pro kannst du mehrere Screenshots gleichzeitig hineinziehen; die aktuellen Einstellungen für Hintergrund, Rahmen, Layout und Bildunterschrift werden auf jedes Bild angewendet, und alle Ergebnisse werden als eine ZIP-Datei heruntergeladen. Die kostenlose Version gestaltet einen Screenshot nach dem anderen.

Kann ich mit transparentem Hintergrund exportieren?

Ja. Wähle die Hintergrundkachel „Transparent“ und lade als PNG herunter. Schatten, Rahmen und abgerundete Ecken bleiben auf einem transparenten Canvas erhalten, sodass du das Mockup auf jeder Folie, Website oder in jedem Design platzieren kannst. JPG unterstützt keine Transparenz, daher nutzen JPG-Exporte stattdessen einen weißen Hintergrund.
